# Dashboard Visualization Plan (Feb 2026 Revamp)

This document groups charts by their target page and section.

## Page 1: Dashboard (Vital Signs)
**Goal:** High-level project health and roadmap.
- **KPI Summary**: Unique Contributors, Maintainers, Codebase LLOC, and Social Proof.
- **2026 Snapshot**: Current workload distribution by category.

## Page 2: Contributors (The Decentralized Army)
**Goal:** Understanding the humans behind the code.
- **The Engagement Pyramid**: Tiers from "The Core" (Top 1%) to "The Scouts".
- **Cohort Analysis**: First-commit year trends vs. retention.
- **The Galaxy Chart**: Interactive bubble explorer of lifetime impact.

## Page 3: Codebase (Architectural DNA)
**Goal:** Deep dive into software evolution.
- **Category History**: Stacked area chart showing how functional areas grew (Consensus vs. Wallet vs. QA).
- **Risk Distribution**: Pie chart of Codebase weighted by protocol criticality.
- **Tech Stack**: C++ vs. Python vs. Shell evolution.

## Page 4: Engineering (Development Process)
**Goal:** Measuring project velocity and methodology.
- **Toggle: Authored vs. Total Activity**: Distinguishing between code authorship and maintenance merges.
- **Workload Balance**: Distribution of commits across categories.
- **PR Lead Time (WIP)**: Time from first commit to merge (Future).

## Page 5: Health & Culture (Heartbeat)
**Goal:** The project's operational and cultural resilience.
- **The Global Heartbeat**: 24/7 UTC activity heatmap showing project globalization.
- **Regional Evolution**: Growth of contributors by continent (Emerging Regions).
- **The Corporate Era**: Sponsorship trends using `sponsors_lookup.json`.
- **Maintainer Independence**: Ratio of corporate vs. individual maintainers over time.

## Page 6: Methodology (Transparency)
**Goal:** Documenting the forensic logic.
- **Data Lifecycle Flow**: Interactive visual of the ingestion pipeline.
- **Risk Weights Table**: Disclosure of category multipliers (50x-1x).
- **Verified Data Links**: Direct links to raw GitHub assets.
