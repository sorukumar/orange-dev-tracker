## Part 1: Architecture of Truth

### 1.1 The "Priority" Pipeline
We now apply a **Hierarchy of Classification** to every commit:
1. **QA Filter**: Check for `*/test/*` or `test/`. If found, categorize as **Tests (QA)** regardless of depth.
2. **Context Filter**: Check for `doc/` or `.md`. Categorize as **Documentation**.
3. **Logic Filter**: Path-based regex for Consensus, P2P, Wallet, etc.

### 1.2 Intermediate Data Handling
To keep the repository clean and efficient:
- **Source of Truth**: Static JSON files (`aliases_lookup`, `maintainers_lookup`, `sponsors_lookup`).
- **Intermediate Artifacts**: `.parquet` files (ignored by git) handle high-volume processing.
- **Frontend Artifacts**: Lightweight `.json` stats generated by `process.py`.

## Part 2: Critical Logic Revisions (Feb 2026)

### 2.1 The "Maintainer" Fix
**Old Issue**: Any contributor rebasing their own PR appeared as a "Maintainer" due to the `committer_email` field.
**New Solution**: We maintain `maintainers_lookup.json` which contains the PGP-verified "Trusted Circle". Only merges authored by these IDs count toward maintainer metrics. This reduced the "Active Maintainers" count from ~15 (false) to 5-6 (true).

### 2.2 Subsystem Test Prioritization
**Old Issue**: A commit like `src/wallet/test/wallet_tests.cpp` was categorized as "Wallet". This biased development trends toward features rather than safety.
**New Solution**: `Tests (QA)` is now a higher-priority match. All validation code, regardless of which subsystem it lives in, is attributed to the QA effort.

### 2.3 Risk-Weighted Impact
We introduced a tiered weighting system (50x, 30x, 10x, 5x, 1x) to differentiate between protocol-level engineering and auxiliary work. This allows the dashboard to show a "Quality vs. Quantity" view of development.

### Fractional Attribution
To prevent multi-file commits from inflating stats, we use:
`Contribution = (1 / TotalFilesTouched) * Multiplier`
This ensures a single commit never adds more than 1.0 "Standardized Work Unit" to the aggregate history before weighting.
